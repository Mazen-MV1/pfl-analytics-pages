Pocket Frame Lab Analytics

A personal analytics tool designed to monitor the performance of the Pocket Frame Lab YouTube channel.

Application Purpose

The application uses official YouTube APIs to retrieve channel performance statistics and store them in a private Google spreadsheet.

Features

  • Daily channel performance monitoring.
  • Video and Shorts analytics.
  • Audience geography and engagement analysis.
  • Automated daily analytics updates.
  • Content planning and performance reviews.

Data Access

YouTube access is read-only. The application does not publish, modify or delete YouTube videos. Analytics are used by the channel owner and Instinct to support content planning.

This tool is intended for personal use and is not offered as a public service.
